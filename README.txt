INSTALL
1. Back up the existing RAWQ website folder.
2. Replace index.html, style.css, and script.js with the three files in this package.
3. Copy the included assets folder into the same website folder. If assets already exists, merge assets/designs into it; do not delete unrelated files.
4. Keep the directory structure:
   index.html
   style.css
   script.js
   assets/designs/*.webp
5. Open index.html and click each collection to test.

The enquiry buttons use rawqwears@gmail.com. Change that address in script.js if you use another email.
Prices are sample listing prices and should be checked before publishing. The enquiry action opens the visitor's email app; it is not a checkout/payment gateway.
